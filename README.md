## Introduction

Task Management Dashboard built using React.js & Tailwind CSS, focused on productivity and Clean UI with interactive animations.

## Features

- Create, edit and delete tasks.
- Real-time search filtering.
- Due date scheduling.
- Priority levels (Immediate, High, Medium, Low).
- Fully responsive design.

## Installation

To run this project locally, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/thamizhselvan-dev/GSAP-Animation-Task.git
   cd Task-Management

   ```

2. Install the dependencies:

   ```bash
   npm install

   ```

3. Start the development server:

   ```bash
   npm start

   ```

4. Open your browser and navigate to http://localhost:3000
